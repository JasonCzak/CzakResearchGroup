Current and developing projects in the group. Each project is owned by a student researcher, with weekly meetings and regular presentations.

### Spatial parameter functions in the Gray–Scott model
Oscillatory functional forms spatially modulate model parameters so that behaviors characteristic of different regimes can coexist within one lattice.
*Pattern formation · Gray–Scott model*

### Localized pattern manipulation
Localized parameter changes, electric-field effects, and time-delayed feedback protocols are used to generate and control novel nonlinear patterns.
*Control · Nonlinear dynamics*

### Time-step sensitivity in chaotic simulations
Tests when Euler integration stops giving reliable results across dynamical regimes and near transitions. Led by Owen Jones; see [Publications]({{ base_path }}/publications/).
*Numerical methods · Chaos*

### Self-replicating dynamics across diffusion ratios
How self-replicating spot patterns change as the ratio of the two diffusion coefficients is varied.
*Pattern formation · Nonlinear dynamics*

### Spatiotemporal SIR modeling
A two-dimensional patch-based epidemic model introduces local interactions and movement into classical SIR, SEIR, and SIRS frameworks.
*Mathematical epidemiology*

### Dendritic growth
A new computational pattern-formation project. Methods and results will be added as the project develops.
*New project*

### Tree-canopy and ecological data
An open computational ecology project using spatial tree-canopy data as a basis for forest-dynamics analysis.
*Open project*
