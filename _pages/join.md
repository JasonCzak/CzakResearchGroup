We welcome JMU students from physics, computer science, mathematics, and data science, including first-year students. Prior research experience is not required.

For an introduction to the group, the Gray–Scott model, and how new members get started, see the outreach slides: [**Patterns Everywhere** (PDF, 17 slides)]({{ base_path }}/files/patterns-everywhere-czak-group.pdf).

## What students work on

- **Computational physics:** build, test, and analyze simulations of nonlinear physical systems.
- **Mathematical modeling:** translate scientific questions into models that can be explored computationally.
- **Scientific data analysis:** visualize simulation output, compare parameter regimes, and identify meaningful dynamical behavior.
- **Research communication:** prepare posters, talks, abstracts, and reproducible project records.

## Skills you can develop

- Python and C++ programming
- Numerical methods and simulation
- Data analysis and scientific visualization
- High-performance and GPU computing
- Git, GitHub, and reproducible research workflows
- LaTeX, technical writing, posters, and oral presentations

## Getting started

New members start with a starter research paper and a manageable first task: learn the model, reproduce and explain an established result, then build and test the computational tools before contributing to a larger problem. Generative AI and LLM tools are not used during this initial training; the goal is to understand how the equations, code, and physics connect. Returning students mentor new ones, and every student presents at least once a year.
